# Contributing to MCreator

This project focuses on creator website templates.

## Propose a change
- Search existing issues and pull requests first.
- Describe the problem, intended behavior and affected users.
- Keep each pull request focused and document behavior changes.
- Do not commit credentials, personal information or unlicensed third-party assets.

## Verification
- List exact test or build commands and their results; explicitly state which checks were not run.
- Include reproducible steps and representative inputs for bugs.
- Use synthetic or authorized public data in examples and screenshots.
- Document limitations and compatibility or migration impacts.

## Project-specific guidance
Verify offline dependencies, browser compatibility and asset redistribution rights.

## Licensing and security
Public repository visibility does not by itself grant reuse rights. Check the repository's actual license and upstream/asset terms before redistribution. Report exploitable vulnerabilities privately through GitHub's available security reporting channel or a maintainer contact; do not publish exploit details in an issue.

## Review
Maintainers may request changes or further evidence before accepting contributions.
